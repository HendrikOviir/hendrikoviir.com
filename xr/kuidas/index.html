🔌 Kaart 1

Arvuti alati laadijas + wifis

🎯 Mis: Arvuti on 24/7 vooluvõrgus, netis ja ei jää magama.

💡 Miks: Agendid, scheduled taskid ja Remote Control jooksevad ARVUTIS. Kaas kinni, uni või võrk ära = kõik seisab.

✅ Kuidas:

  1. 🔋 Hoia laadija küljes.
  2. 📶 Hoia wifi sees.
  3. ⚙️ System Settings → Battery/Lock Screen: väljalülitus "Never" (laadijal).
  4. 💡 Kaant ära sulge, kui agent töötab.

🔐 Kaart 2

Paroole ei kleebi chatti

🎯 Mis: Paroolid ja API võtmed ei lähe vestlusesse.

💡 Miks: Vestlus salvestub. Parool seal on lekkinud parool.

✅ Kuidas:

  1. 🔑 Paroolid jäävad paroolihaldurisse.
  2. ⌨️ Logi ise sisse brauseris, agent ootab.
  3. 🗝️ Võtmed: secrets/ fail, mida agent ei prindi. Või connectori login.
  4. ❌ Kui kogemata kleebid: muuda parool kohe.

3
🌅 Kaart 3

Handoff igal õhtul

🎯 Mis: Iga õhtu üks handoff-fail, hommikul uus vestlus.

💡 Miks: Pikk vestlus läheb aeglaseks, unustab ja sööb limiiti. Fail viib konteksti uude vestlusse.

✅ Kuidas:

  1. Ütle õhtul: "handoff" (kopeeri kast ülevalt).
  2. XAR kirjutab handoff-xar.md ja nimetab vestluse ümber.
  3. Hommikul ava uus vestlus ja kleebi esimene sõnum.
  4. 🔔 Teine handoff, kui vestlus on ~180k tokenit pikk. XAR võib seda ise pakkuda.

🔗 Kaart 6

Tailscale: telefon ↔ Mac

🎯 Mis: Turvaline privaatvõrk Sinu Maci ja iPhone'i vahel. Saad Xari ja Sinu Silla (dash) telefonist lahti teha, ka väljaspool kodu.

💡 Miks: Agent töötab Macis. Tailscale'iga näed tema tööd ja annad kinnituse ükskõik kust, ilma et midagi oleks avalikult internetis.

✅ Kuidas:

  1. Laadi Tailscale Maci (tailscale.com/download) ja iPhone'i (App Store).
  2. Logi mõlemas sisse sama Google'i kontoga.
  3. Lülita mõlemas sisse (Connected). Maci nimi ilmub telefoni nimekirja.
  4. Ütle Xarile: "Tailscale on sees". Ta seab Silla telefonist avatavaks.

HELM, crew board, raha, KPI

🎯 Mis: Neli lehte, igaühel oma töö.

💡 Miks: Üks vaade ühele küsimusele. Ei otsi.

10
📈 Kaart 10

Tokenite kasutus

🎯 Mis: Tea, palju limiiti on veel alles.

💡 Miks: Limiit saab otsa keset tööd = seisak.

✅ Kuidas:

  1. Claude app → Settings → Usage: 5-tunnine aken + nädala limiit.
  2. Vaata päeva alguses ja keskpäeval.
  3. Küsi agendilt: "kui palju limiiti alles?"
  4. Rasked ehitused: abilised (Sonnet), säästavad limiiti.

💳 Plaan: alusta Pro-ga (~23 €). Kui limiit lõpeb iga päev: teine Pro konto (eraldi aju) või Max 5× (~90 €/kuu). Kui agendid töötavad päev läbi ise: Max 20× (~180 €/kuu).

Git push + varukoopia

💡 Miks: Kui arvuti hangub või kaob, jääb töö alles ja saad tagasi keerata.

  2. Enne suurt muutust: eraldi commit.
  3. 💾 Varukoopia: väline ketas või pilv.
  4. ❓ XAR küsib esimesel päeval: kus XR kausta koopiad elavad?

  5. 🛠️ skills/ (agents/*/SKILL.md) = juhend ühe töö jaoks.
  6. 🔒 private/ = tundlik, ei lähe avalikku.

  3. Esimene kord: vajuta käsitsi Run now, et load kinnitada.
  4. Seejärel jookseb ise.

♨️ Kaart 14

Soojenduse task

🎯 Mis: Pisike sõnum ~3 h enne tööd käivitab 5-tunnise akna.

💡 Miks: 5-tunnine aken algab esimesest sõnumist. Nii lähtestub see ~2 h tööpäeva sees: ~2 h tokenit + uus 5-tunnine aken.

✅ Kuidas:

  1. Kleebi kast agendile (muuda kellaaeg: tööpäeva algus − 3 h).
  2. Käivita üks kord Run now.
  3. Arvuti peab olema sees ja netis (vt 2. kaart).

🛡️ Kaart 15

Arvuti ligipääs (computer use)

🎯 Mis: Agent teeb ekraanipilte, klikib, kasutab mikrofoni, vahetab taustapildi.

💡 Miks: Ilma loata ta ei näe ega klõpsa midagi.

✅ Kuidas:

  1. System Settings → Privacy & Security.
  2. Luba Claude: Screen Recording, Accessibility, Microphone.
  3. Agent küsib iga äpi kohta ("request access"), sina vajutad Allow.
  4. Brauserid on ainult lugemiseks, neile on Chrome extension.

🔊 Kaart 18

Hääl

🎯 Mis: Agent räägib vastuseid ette.

💡 Miks: Jalutades kuulad, laua taga loed.

✅ Kuidas:

  1. /speak-on = hääl sisse (lülitub 2 h pärast ise välja). /speak-off = välja. /shh = peata praegune.

  3. 🗣️ Fish Audio: häält valib vastuse keel. Eesti ja inglise töötavad, rootsi tuleb lisada.
  4. 🚫 Koodi, linke ja mustandeid ei loeta ette.

♿ Batch 5 · Ligipääsetavus

21
🖥️ Kaart 21

Mode12 / Mode22 / Mode32

🎯 Mis: Kolm valmis töölaua vaadet. Ütled sõna, agent seab aknad ja taustapildi.

💡 Miks: Ei pea akent-akna haaval lohistama. Õige vaade õigel ajal hoiab pea selge.

✅ Kuidas:

  1. ☀️ Mode12 = hele töölaud (päev): aknad paika, hele taustapilt.
  2. 🌙 Mode22 = tume töölaud (öö): sama paigutus tumedas vaates, tume maastik või kosmos.
  3. 🧘 Mode32 = rahulik HELM-vaade: üks ekraan täis HELM rahulikus režiimis, teisel ekraanil HELM avatud; taustaks kosmos.
  4. 🪟 Agent seab aknad ja taustapildi ise. Sina ütled ainult sõna.
  5. ⚙️ Lisa oma paigutus: ütle agendile "tee mulle Mode42" ja kirjelda, mis kus olema peab.
